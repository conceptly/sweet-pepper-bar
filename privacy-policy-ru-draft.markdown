## 4. Формы и контакты

4.1. Обязательными в формах отмечаются сведения, без которых нельзя обработать соответствующий запрос. Непредоставление необходимого контакта может сделать ответ невозможным; для просмотра меню отправлять форму не требуется.

4.2. Если обработка через форму основана на согласии, перед отправкой пользователь отдельно отмечает изначально пустое поле согласия. Текст согласия доступен до отправки; Оператор сохраняет подтверждение его получения. Ознакомление с Политикой не подменяет отдельное согласие.

> **Перед публикацией согласия:** проверить доступность /consent/ и /en/consent/ без входа в WordPress, актуальность версии текста и поступление письма со строкой подтверждения. Код проверки галочки и записи версии, времени и IP уже есть; в предоставленных тестовых письмах эта строка не показана.

4.3. Оператор использует контакт для ответа по выбранному вопросу. Отправка обращения не означает подписку на рекламу. Получение сообщения через мессенджер не освобождает Оператора от обязанностей по обработке полученных сведений.

4.4. Сообщения из форм отправляются через почтовый сервис Timeweb на hello@sweetpepper.bar. Яндекс Почта автоматически получает письма из этого ящика с помощью сборщика и сохраняет их в почтовом ящике директора Оператора (p020885@yandex.ru). Копии обращений также поступают в рабочий почтовый ящик генерального менеджера в Яндекс Почте; он используется для ответов и работы с вопросами гостей. Удаление охватывает копии в обоих сервисах и другие рабочие копии. Запись телефонных разговоров не ведётся. Тема сайта не создаёт отдельный архив текстов обращений в базе WordPress; почтовые ящики и возможные технические копии у провайдеров учитываются отдельно.

4.5. Для ограничения повторных отправок сервер временно хранит хеш IP-адреса и счётчик обращений. Срок действия счётчика — один час после обновления; истёкшие технические записи удаляются средствами WordPress. В письмо включаются данные формы, выбранные получатели из команды, язык и адрес страницы, а также подтверждение согласия с датой, временем, версией текста и IP-адресом.
